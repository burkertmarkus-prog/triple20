# Eigene Produktbilder

Lege hier ausschließlich eigene oder ordnungsgemäß lizenzierte Produktbilder ab. Unterstützte Formate: AVIF, JPG/JPEG, PNG und WebP.

Empfehlung: quadratisches oder leicht hochformatiges Bild, mindestens 800 × 800 Pixel, möglichst unter 500 KB. Verwende einfache Dateinamen ohne Leerzeichen, Umlaute oder Sonderzeichen, zum Beispiel `dartboard-training.webp`.
